# 《第一场雨》故事设定

森林圣湖版对应[漫画分镜](OpeningDesign.md)、[场景设计](Scene.md)和[玩法与实现](Architecture.md)。旧地图的四页开场仍可从[旧版分镜](OpeningDesign.md#现有沙漠原型分镜)查阅。

## 圣湖与结界

古森林深处有一片被低雾藏住的圣湖。花精灵住在湖心小岛的圣树下，照看岛上的幼苗。圣树的根能引来林下泉水，岛上新树扎根并继续成长后，更多细小泉眼通向湖盆；枝叶蒸腾又把一部分水送回湖上的云。湖与云相互补给，却共用同一份有限的圣水。林外流传着圣水能治愈枯败的传说，怪物却想拿它维系自己正在开裂的躯体和盔甲。

白天，日光从树冠一侧照进湖盆。精灵能看清四处岸线，外林的低雾遮住了更远的地形。古老结界拦住外来者。

## 第一场雨

白日里，怪物在枯死的林外找到一块刻着树岛的旧石片。它们循着旧石片来到北侧雾外。披甲施术者用堕落魔法撕开银色结界，一只蜘蛛先穿过缺口，踏上湖边的苔土。破口随后沿结界蔓延，林中的怪物便能从几处岸线分别接近。

蜘蛛用暗紫法术将一缕圣水从湖面牵到自己身上。苔岩上露出一条高过水面的深色湿痕。精灵飞回圣树下，把手按在仪式石上。湖中的一部分水裹着圣力升过树冠，在湖上聚成一整朵雨云。云影投下来时，湖水又低了一截。

第一阵雨落在蜘蛛身上。它的腿撑不住，牵住圣水的紫光逐渐散开。更远处的雾里还有别的影子。精灵停在岛东侧，脚边是仍干燥的空地。整朵云继续落下圣雨，她留下一颗种子，准备让新树恢复圣湖；玩家在此接手。

## 守住之后

击败来袭的首领且湖中仍有圣水，意味着精灵守住了这一次入侵；新树与成长让恢复仍有希望。湖水被抽干则圣湖失去力量，守望失败。当前游戏用胜负界面交代结果；专门的结局镜头属于表现设计，不作为已完成的玩法。 [胜负规则](Architecture.md#森林圣湖怎么玩和怎么读)

## 统一规则

| 设定 | 画面与玩法中的含义 |
|---|---|
| 低雾与结界 | 低雾沿外林环绕湖盆，近处水线和干岸清楚可见。堕落魔法破坏的是结界，怪物随后能从不同方位穿过雾。 |
| 圣湖与雨云 | 圣湖是储水池，雨云是精灵短期可用的水。召云和之后的补云都将一部分湖水转移到云里。 |
| 两种力量 | 堕落魔法以暗紫裂纹和逆向水流辨认。圣雨借湖的力量驱退入侵者，落到盔甲上溅开，打在暴露的皮肤上产生受击反应。 |
| 岛上的树 | 精灵可在湖心岛空地自由选点种树，一局最多六棵、每棵三级；扎根后的有效成长提高湖水恢复、湖云容量与整片云的雨量和雨伤。容量变大不凭空生成水，水量增减改变水线。 |
| 精灵与天气 | 大片基础雨守护四岸，精灵把同一份水中的一部分集中为雨、雪或冰雹；局部加强有资源与其他方向减弱的代价。 |
| 圣湖的回应 | 击退精英后，圣湖给予圣雨、霜雪或冰雹方向的祝福。选择帮助这一局守望，不凭空创造圣水。 |
